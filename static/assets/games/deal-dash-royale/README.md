# Deal Dash Royale asset pack

These are original Mak3Deals game visuals generated for this project with the built-in image generation tool. They are organized separately from the game code so the same art can be reused in future browser games.

## Files

- `runner-cutout-v1.png` — primary player character cutout with transparency; intended for the player sprite and menus.
- `character-lineup-v1.png` — four-color competitor lineup; intended for character selection, loading screens, and promotional art.
- `obstacle-kit-v1.png` — rotating gate, spring pad, bumper pillar, and deal token; intended as a visual reference sheet while wiring the actual collision objects.
- `skyline-course-v1.png` — wide obstacle-course key art; intended for the arena backdrop, course selection, and game-room cards.

## Art direction

The pack uses a bright teal, coral, gold, and violet palette with chunky readable silhouettes. The designs are original and do not copy Fall Guys, Mario Kart, Candy Crush, or other named game characters.

The current obstacle sheet is a presentation sheet with a soft studio background. For gameplay collision and layering, the final implementation should use code-drawn or separately extracted props so the background does not interfere with play.
